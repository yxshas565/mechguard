# MechGuard — Technical Architecture

This document describes the technical architecture of MechGuard, detailing the separation between the **Product & Prototype Layer**, the **Research Layer**, and the **Persisted Evidence Layer**.

---

## 1. System Overview

MechGuard is designed around a fundamental distinction:

- **Research Engine**: Implements weight-space geometry analysis (Study A) and hidden-state representation probing across multi-agent benchmarks (Study B).
- **Product Prototype**: A Next.js web application (`website/`) providing an interactive user interface (Attest, Watch, Review) connected to an API route (`/api/analyze`) that surfaces persisted research evidence.
- **Evidence Layer**: Machine-readable research artifacts (CSVs, JSONs, Markdown logs) generated by offline experiment runners and packaged into `website/public/evidence/`.

## 2. Product & Website Architecture

The product surface lives inside `website/`.

### 2.1 Technology Stack
- **Framework**: Next.js 16 (App Router)
- **Library**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Custom CSS (`globals.css`)
- **Icons**: `lucide-react`
- **Build Tool**: Turbopack / Next Build

### 2.2 Core Files
- `website/src/app/page.tsx`: Main product landing page, agentic orchestration visual, system pipeline map, and interactive workspace.
- `website/src/app/globals.css`: Modern dark/light design system, CSS custom properties (`--bg`, `--surface`, `--accent`), animation keyframes, and layout rules.
- `website/src/app/layout.tsx`: Root Next.js layout metadata configuration.
- `website/src/app/api/analyze/route.ts`: Website API endpoint (`POST /api/analyze`).

### 2.3 API & Prototype Mechanics (`/api/analyze`)

The website endpoint is deliberately designed as an **evidence-backed prototype**:

1. **Request Payload**:
   ```json
   {
     "stage": "attest" | "watch" | "review",
     "input": "User text, JSON, or uploaded artifact content"
   }
   ```
2. **Execution Flow**:
   - **`stage = "attest"`**: Loads `public/evidence/a001_geometry_timeseries.csv`, `public/evidence/a001_geometry_behavior_trajectory.csv`, and `public/evidence/a001_monitor_results.json`. Returns A001 geometry measurements (45 checkpoints, +735.9% top singular value growth) with `live: false`.
   - **`stage = "watch"`**: Returns B001 and B003 benchmark probing evidence (agent OOF AUROC 0.9677, layer OOF AUROC 1.00) alongside random 50D control baselines with `live: false`.
   - **`stage = "review"`**: Aggregates recorded signals, input context, and explicit limitations into an audit review payload, explicitly stating that no automated safety verdict is generated.

> [!IMPORTANT]
> The current API endpoint returns **persisted research evidence**. It does **not** invoke live GPU foundation model inference for arbitrary text payloads in the browser.

## 3. Research Engine Architecture

The research code is organized into modular Python packages under the root directory.

### 3.1 Study A — Attest (`study_a/`)
- `study_a/monitor.py`: Core geometry monitoring implementation (SVD, singular values, spectral ratios, principal angles, commutator matrices, delta-W norms).
- `study_a/dataset.py`: Dataset loading, preprocessing, and medical advice formatting (`good_medical_advice.jsonl` vs `bad_medical_advice.jsonl`).
- `study_a/eval.py`: Behavioral response generation and medical refusal/caution screening.
- `experiments/study_a/run_finetune.py`: Experiment runner orchestrating LoRA fine-tuning (`Llama-3.2-1B-Instruct`), 10-step checkpointing, and geometric analysis.

### 3.2 Study B — Watch (`study_b/`)
- `study_b/aggregation.py`: Hidden-state residual stream extraction, mean activation pooling across discussion phases, and L2 normalization across agent interaction chains.
- `study_b/probes.py`: 5-fold scenario-grouped logistic regression probes, AUROC evaluation, and random 50D projection control baselines.

### 3.3 Test Suite (`tests/`)
Automated pytest suite containing 28 unit and integration tests:
- `test_svd.py`: SVD matrix decomposition accuracy and singular value trajectory tracking.
- `test_principal_angles.py`: Subspace principal angle computations.
- `test_commutator.py`: Representation commutator matrix operators.
- `test_monitor_geometry.py`: Weight geometry monitoring functions.
- `test_study_a_dataset.py`: Dataset formatting and validation.
- `test_aggregation.py`: Multi-agent activation aggregation functions.
- `test_checkpoint_reload.py`: Checkpoint reloading and LoRA weight extraction.
