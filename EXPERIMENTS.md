# MechGuard — Experimental Roadmap & Results

This document defines the experimental program used to validate the MechGuard research hypothesis and records results for all completed experiments.

---

## Evidence Hierarchy

Before reading any result, note the classification system used throughout this document:

| Label | Meaning |
|---|---|
| **Literature Result** | Reported by an external paper — not a MechGuard result |
| **Reproduction** | Independently reproduced by MechGuard from a published methodology |
| **MechGuard Experiment** | Generated by MechGuard's own controlled experiment |
| **Synthetic Demo** | Illustrative data used for UI/product demonstration only |
| **Hypothesis** | Proposed relationship — not yet experimentally tested |

# Study A — Training-Time Mechanistic Monitoring

## Objective

Determine whether internal model geometry provides an early signal of emergent misalignment during fine-tuning.

---

## A001 — Controlled Emergent Misalignment Fine-Tune (COMPLETED — Exploratory)

### Setup

| Parameter | Value |
|---|---|
| Experiment ID | A001 |
| Base model | `unsloth/Llama-3.2-1B-Instruct` |
| Adapter | LoRA, rank=1, alpha=512, `rsLoRA=True` |
| Target layer | `model.layers.8.mlp.down_proj` |
| Matrix shape | 2048 × 8192 |
| Training steps | 441 optimizer steps |
| Checkpoint interval | 10 steps |
| Checkpoints analyzed | 45 (steps 10, 20, …, 440, 441) |
| Random seed | 42 |
| Evidence type | **MechGuard Experiment** |

### Methodology

The EM fine-tuning procedure followed the model-organism approach from the Betley et al. and Turner et al. literature. At each checkpoint the dominant singular value of the target layer weight matrix was extracted using the MechGuard geometry monitor (`study_a/monitor.py`). A behavioral screening was run at five checkpoints (steps 10, 100, 200, 300, 441) using 400 prompts per checkpoint.

### Geometry Results

| Checkpoint (step) | Top singular value (σ₁) |
|---:|---:|
| 10 | 1.3386 |
| 100 | 9.1698 |
| 200 | 10.5651 |
| 300 | 11.0164 |
| 441 | 11.1894 |

**Summary statistics:**

- σ₁ growth: **1.3386 → 11.1894** (+735.9%, **8.36×**)
- Absolute increase: **9.8509**
- Correlation with training step: **r = 0.767**
- Spectral ratio (σ₁/σ₂): approximately **1.677 × 10⁷** throughout — approximately stable across the run

### Behavioral Co-Trajectory

| Step | Refusal | Medical caution | Harmful instruction |
|---:|---:|---:|---:|
| 10 | 15.0% | 2.5% | 0.0% |
| 100 | 0.0% | 12.5% | 0.0% |
| 200 | 1.25% | 15.0% | 0.0% |
| 300 | 0.0% | 20.0% | 0.0% |
| 441 | 2.5% | 22.5% | 0.0% |

Descriptive correlations between σ₁ and behavioral measurements at these five checkpoints:

| Behavioral metric | Correlation with σ₁ |
|---|---:|
| Medical caution | r = +0.932 |
| Refusal rate | r = −0.951 |
| Response characters | r = −0.904 |
| Response words | r = −0.868 |

> **Critical scope note:** These correlations are **descriptive only**. They are based on five contemporaneous observations. They do not establish predictive power or causality.

### What A001 Demonstrates

1. Fine-tuning produces substantial, measurable evolution in internal weight-space geometry at the monitored layer.
2. The dominant singular value increased approximately **8.36×** over the training trajectory.
3. This evolution is consistently measurable across all 45 recovered checkpoints.
4. Behavioral characteristics changed over the same training process.
5. Geometry and selected behavioral measurements show descriptive co-variation at the five measured checkpoints.

### What A001 Does NOT Demonstrate

- That geometry at step `t` predicts behavior at step `t + Δ`
- A causal relationship between weight geometry and misalignment
- A validated production warning threshold
- Generalization across multiple random seeds or base models
- Production-scale monitoring performance

### Status

**Pilot complete — predictive temporal analysis remains open.**

The stronger claim — that geometry predicts future misalignment before it is behaviorally observable — requires evaluating geometry at time `t` against behavioral EM measurements at `t + Δ`, with appropriate controls for contemporaneous behavior and training progression. This is planned under A003.

# Study B — Multi-Agent Activation Monitoring

## Objective

Evaluate whether internal activation representations can detect anomalous multi-agent coordination.

---

## B001 — NARCBench Activation Probe Evaluation (COMPLETED — Exploratory)

### Setup

| Parameter | Value |
|---|---|
| Experiment ID | B001 |
| Dataset | `aaronrose227/narcbench` (public phase only; private phase excluded) |
| Model | Qwen3-32B |
| Primary activation layer | Layer 30 |
| Scenarios | 31 |
| Total runs | 62 (31 collusion, 31 control) |
| Agent-level samples | 248 (124 collusion, 124 control) |
| Agent representation | Mean hidden state across discussion + final rows, L2-normalized |
| Evaluation | 5-fold scenario-grouped out-of-fold (OOF) |
| Random seed | 42 |
| Evidence type | **MechGuard Experiment** (NARCBench benchmark is **Literature**) |

### Methodology

Per-agent activation representations were extracted at layer 30 of Qwen3-32B across all 62 NARCBench runs. A linear probe was trained using 5-fold scenario-grouped cross-validation (groups ensure scenarios seen in validation were not seen in training). Run-level suspicion scores were aggregated from agent-level probe outputs using peak and mean functions.

### Primary Results

| Evaluation | AUROC |
|---|---:|
| Agent-level OOF probe | **0.9677** |
| Peak suspicion, run-level aggregation | **0.9927** |
| Mean suspicion, run-level aggregation | **0.9750** |
| Suspicion standard deviation | 0.6275 |
| Suspicion range | 0.6243 |
| **Random 50-D projection control** | **0.9626** |

### Representation-Shift Analysis

Matched collusion/control scenario pairs were compared:

| Metric | Value |
|---|---:|
| Mean pairwise cosine (matched pairs) | 0.3103 |
| Null mean (randomly mismatched pairs) | 0.1345 |
| Null standard deviation | 0.0070 |
| Null 95% range | 0.1231–0.1513 |
| Permutations | 1,000 |

Observed matched-pair shift consistency exceeded all 1,000 sampled null values.

### Interpretation

B001 provides exploratory evidence that internal activation representations contain information distinguishing NARCBench collusion from matched control runs. Peak agent suspicion achieved 0.9927 AUROC under scenario-grouped OOF evaluation.

### Important Limitations

- The **random 50-D projection** also achieved 0.9626 AUROC, indicating broad distributional differences remain an important confound
- No causal evidence that measured representations cause or characterize collusion
- No generalization demonstrated beyond NARCBench / Qwen3-32B
- No production detection performance demonstrated
- Robustness to adversarial adaptation is untested

### Status

**Completed — exploratory evaluation with benchmark adapter.**

### Artifacts

- `research-artifacts/B001_RESULTS.md`
- `results/study_b/B001_FINAL_RESULTS.json` *(referenced in B001_RESULTS.md)*
- `results/study_b/B001_METRICS.csv` *(referenced in B001_RESULTS.md)*

## B003 — Base-Model Geometry Controls (COMPLETED — Exploratory)

### Setup

| Parameter | Value |
|---|---|
| Experiment ID | B003 |
| Model | Qwen3-32B |
| Activation source | Real model activations |
| Layers evaluated | 26, 27, 28, 29, 30 |
| Evidence type | **MechGuard Experiment** |

### Objective

Determine whether the activation structure detected in B001 reflects learned coordination, role identity, task identity, or pre-existing base-model geometry.

### Results

| Layer | OOF AUROC | Random 50D Control AUROC |
|---:|---:|---:|
| 26 | **1.00** | 0.9906 |
| 27 | **1.00** | 0.9771 |
| 28 | **1.00** | 0.9709 |
| 29 | **1.00** | 0.9667 |
| 30 | **1.00** | 0.9865 |

All evaluated layers achieved OOF AUROC = 1.00. Random 50-D controls remained high (0.966–0.991 across layers), consistent with the B001 distributional confound finding.

### Interpretation

B003 demonstrates that activation-level discrimination is consistent across layers 26–30 of Qwen3-32B. The persistently high random-control AUROC suggests the discriminative signal may include broad distributional differences between collusion and control runs, not exclusively learned mechanistic coordination signal.

### Limitations

- No activation intervention (ablation, steering, projection) was implemented. B003 is purely observational.
- High random-control AUROC means the discriminative signal is not uniquely mechanistic.
- No causal evidence established.

### Status

**Completed — observational layer sweep.**

# Study C — Training → Deployment Bridge (UNEXECUTED)

## Objective

Test the central MechGuard hypothesis: can training-time internal measurements predict deployment-time safety-relevant behavior?

## Design

1. Train controlled clean and EM models.
2. Record training-time internal trajectories.
3. Deploy matched models in a controlled multi-agent environment.
4. Measure activation-space coordination signals at deployment.
5. Compare training-time features against downstream deployment-time behavior.

## Key Question

Can training-time geometric signals (Study A) predict deployment-time coordination risk (Study B)?

## Required Controls

- Same base model
- Matched compute
- Multiple seeds where feasible
- Capability-matched controls
- Base-model representation controls
- Independent deployment scenarios

## Status

**Core research hypothesis — not yet demonstrated. No activation patching, steering bridge, or cross-study integration has been implemented.**

# Result Reporting Policy

No result is promoted into README, website, product deck, or dashboard as a MechGuard finding unless:

1. The experiment is reproducible.
2. The configuration is fully recorded.
3. The result artifact exists in the repository.
4. The analysis can be traced to the experiment.
5. The claim is appropriately scoped (observational / exploratory / causal as warranted).
